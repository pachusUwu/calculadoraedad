# Calculadora de Edad – Actividad 1 (LPR 2026)

Revisión integral de lógica y algoritmos implementada en **Python** y **C++**. El programa calcula la edad exacta de una persona a partir de su fecha de nacimiento (fecha actual del ejercicio: 8/7/2026) y valida que la fecha exista en el calendario (años bisiestos y días de cada mes).
